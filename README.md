# Jogo de Cintura

Portal editorial sobre trabalho, negócios, tecnologia e carreira, com painel de publicação autenticado.

## Stack

- Portal estático e responsivo publicado no Netlify.
- API Cloudflare Workers e banco Cloudflare D1.
- Painel editorial com matérias, revisão, autores, categorias, tags e histórico.

Consulte `README.md` e `cloudflare/` para operação e configuração.
